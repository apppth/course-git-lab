# Ветки Git Flow

| Ветка | Откуда создаём | Куда вливаем | Зачем |
|-------|----------------|--------------|-------|
| `main` | постоянная | сюда вливают только `release/*` и `hotfix/*` | то, что на проде, с тегами версий |
| `develop` | один раз от `main` | сюда вливают `feature/*`, `release/*`, `hotfix/*` | сборка следующего релиза |
| `feature/*` | `develop` | `develop` через PR | одна задача, не мешает остальным |
| `release/*` | `develop` | `main` (+ тег) и обратно в `develop` | заморозить фичи, поправить баги, поднять версию |
| `hotfix/*` | `main` | `main` (+ тег) и `develop` | срочно починить прод без недоделанных фич |

Как я делал учебный hotfix: ветка `hotfix/apppth-typo` от `main`, исправил «Helo» на «Hello» в `sandbox/hello.txt`, влил в `main` с тегом `v0.1.1` и потом в `develop`.
